# Klutch RLSMP

A BeamMP compatibility bridge for **RLS Career Overhaul 2.8.0**.

Current bridge version: **0.8.1-alpha**. Target environment: BeamNG.drive 0.40 and BeamMP Server 3.9.3. In-game multiplayer validation remains necessary before production use.

Each signed-in player keeps separate local career profiles for each server while sharing the map with other players. Custom RLSMP screens and messages are in English.

## Features

- Native RLS career selection and creation, with multiple profiles per account.
- Copy compatible single-player careers into a separate server profile.
- Three synchronized civilian AI vehicles per active career player.
- **Player Exchange** phone app: persistent public vehicle listings, offline sellers, withdrawals and money transfers.
- Vehicle ownership guards, stable parts replacement and stored-fleet restoration.
- One global audio recovery after the selected career and player are ready.

The career selector has a visible loading/retry presentation for slow first loads. It commits before BeamNG's navigation deadline and acknowledges native route readiness while the RLS profile graph finishes loading.

Read [the feature and behavior guide](docs/FEATURES.md) for transaction recovery and known limits.

## Downloads

Download the versioned assets from [GitHub Releases](https://github.com/embrayage/klutch-rlsmp/releases).

- `RLSMP-0.8.1-server-install.zip`: new installation, including the patched client, server scripts and unique-identity setup helper.
- `RLSMP-0.8.1-update.zip`: existing server; keep its `config.json` and `trades.jsonl`.
- `SHA256SUMS.txt`: SHA-256 checksums for both archives.

GitHub's automatically generated **Source code** archives contain development sources, not a ready-to-install mod. For a new Windows server, extract the installation package into its root and run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Configure-RLSMP.ps1 -ServerRoot .
```

This generates a distinct ID for each new server and preserves existing configuration. Manual/Linux instructions are in `INSTALL.txt`.

## Build

The repository contains the bridge source, patch builder and tests. Obtain the original RLS release separately from [Raceless-RLS](https://www.patreon.com/RacelessRLS/posts/rls-career-v2-8-173221696).

Requirements: **Python 3.11+** and your original `rls_career_overhaul_v2.8.0.zip`.

```powershell
python .uild.py --source "PATH_TO_RLS_ZIP"
```

The builder checks the upstream version and all 17 patch targets. It writes a patched client ZIP, three server scripts, a new local server configuration and a portable update archive under `build/`. It keeps the original RLS archive intact.

## Install on a new server

1. Stop your BeamMP server and back up its files.
2. Build the mod locally as shown above.
3. Copy `build/Resources/Client/rls_career_overhaul_rlsmp_teamx.zip` to the server's `Resources/Client/`.
4. Copy `build/Resources/Server/rlsmpTeamx/` to the server's `Resources/Server/`. The generated `config.json` contains this server's new identity. Keep it after players begin careers.
5. Set `Map = "/levels/rls_west_coast/info.json"` in your existing `ServerConfig.toml`. Keep your own authentication key and network settings. Allow room for player cars and three AI per active player.
6. Keep only the patched RLS provider in `Resources/Client/`; move other RLS versions to a backup directory.
7. Start the server from its root directory. Fully close BeamNG, reconnect with a signed-in BeamMP account, then choose a career.

## Update an existing server

Stop and back up the server. Extract `build/RLSMP-0.8.1-update.zip` into its root directory, replacing the client ZIP and all three server Lua scripts.

**Keep the installed `Resources/Server/rlsmpTeamx/config.json` and `trades.jsonl`.** The update archive excludes both files. Do not replace an established server identity with the identity generated by a fresh build.

Restart the server. Every player must fully close BeamNG and reconnect.

## Player data

Career saves live on each player's PC under the BeamNG user folder:

```text
settings/rlsmpTeamx/saves/<serverId>/beammp_<account>_<profile>/
```

Keep the server's `config.json` and `trades.jsonl` together in backups. Importing a solo career copies it; the original stays in place. Completed trades must not be undone by restoring just one old career.
